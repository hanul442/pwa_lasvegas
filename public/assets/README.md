# VEGAS Runtime Assets

Generated/approved production assets live under this directory.

## Structure
- `shared/backgrounds`
- `shared/textures`
- `shared/abstract`
- `shared/marketing`
- `lobby`
- `games/blackjack`
- `games/roulette`
- `games/dice`
- `games/poker`

Do not add generated assets without updating `docs/assets/asset-registry.json`.
Source prompts and QA outcomes belong in the registry/log, not in filenames.
