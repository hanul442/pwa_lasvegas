# Table sounds

Every file in this folder is a recording from **Casino Audio (1.1)** by Kenney Vleugels,
https://kenney.nl/assets/casino-audio, licensed **CC0 1.0** (public domain). The pack's
`License.txt`: "You may use these assets in personal and commercial projects. Credit (Kenney or
www.kenney.nl) would be nice but is not mandatory."

The files keep the pack's own names (`chips-stack-3.m4a` is the pack's `Audio/chips-stack-3.ogg`),
except `card-deal-*` (the pack's card slides), `card-place-*` (card places), `card-gather-*`,
`card-fan` and `card-shuffle`. Each was cut to the part with sound in it, mixed to mono, brought to
the same peak level and encoded as AAC (.m4a) so Safari on iPhone decodes it too. The cut, mono
versions were taken from the CC0 sound sets bundled in the npm packages
`@johnmorrisdotca/toranpu` (cards), `@johnmorrisdotca/jarajara` (chips) and
`@johnmorrisdotca/korokoro` (dice), which document the same source and licence.
